# Server Locations

Choose the server location closest to your players for the best performance and lowest latency.

## Available Locations

### North America
- **United States** - Ashburn, Virginia

### Europe
- **Germany** - Frankfurt and Falkenstein
- **France** - Gravelines
- **Finland** - Helsinki
- **Poland** - Warsaw

### Asia-Pacific
- **Singapore** - Excluding CS2

Our US and Singapore locations run on standard performance hardware. The other locations run on our high-performance AMD NVMe servers.

## Free and Pro Availability

Not every location takes both Free and Pro servers, and not every game is offered in every location. To see what is available right now:

| Where | What it shows |
|-------|---------------|
| [Network Test](https://fshost.me/network) | Every location and machine, each marked **Free**, **Pro** or both, with a ping test. You need to be logged in |
| [Pro pricing page](https://fshost.me/pro/pricing) for your game | The locations you can order a Pro server in |
| The free server page for your game, from [Games](https://fshost.me/games) | The locations that take free servers for that game, with how many free servers are still **available** |

Each location has a limited number of free servers. When a location is full, pick another one or try again later. Pro locations can sell out too, and then show **Sold out** when you create a server.

### Future Locations

We're open to adding more locations based on demand and pricing. We'd need at least 10 Pro users interested in a location to make it viable.

## How to Choose a Location

1. **Player geography** - Where are most of your players located?
2. **Latency** - Choose the location with the lowest ping for most of your players
3. **Availability** - Check that the location offers your game on the tier you want

::: tip Testing Latency
Before creating your server, [test your ping to our locations](/network/ping-test) to find the best one for your players.
:::

## Changing Locations

You cannot move a server to another location yourself.

- **Free servers** only last while you play. Pick a different location the next time you create one.
- **Pro servers** can be moved by us. Open a ticket on [Pro Support](https://fshost.me/pro/support). The server gets a new IP address and port. See [Server Moves](/servers/pro/server-moves).

If you regularly need servers in several regions, create a separate Pro server in each location.
