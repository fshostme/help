# Pro Server List

The server list shows every Pro server you own or help run, with quick controls for each one.

## Accessing the Server List

Click the server icon next to your balance in the top menu, or **Servers** in the Pro Panel menu. You can also go straight to **[fshost.me/pro/servers](https://fshost.me/pro/servers)**.

## Your Servers

**Your servers** lists the servers you own. Click a server to open its page. See [Managing Your Server](/servers/pro/managing-server).

Each server shows:

| Item | What it shows |
|------|---------------|
| **State dot** | The server's state. Hover over it to see the state by name. See [Server States](#server-states) |
| **Server ID** | The ID, such as **P1234**. Include it when you ask support for help |
| **Flag** | The server's country. Hover over it to see the machine and country |
| **Game and address** | The game, then the IP and port. Click the address to copy it |
| **Players** | Players online and slots, while the server is running |
| **Price** | The monthly price, shown to the owner |
| **Renewal** | When the server renews or expired. Hover over it for the exact date. For the owner it also says **auto renews** or **manual renew**, which links to the **Billing** tab |
| **Buttons** | **Start**, **Stop** and **Restart**, depending on the state, and **Edit** to open the server's settings |
| **Bottom line** | The number of team members, your **Description** (or **No description**) and, while the server is running, its hostname |

A server that has not been configured yet shows a **Setup** button instead of **Edit**. See [Creating a Pro Server](/servers/pro/creating-server).

A banner on the server says **Server expired** when it needs renewing, or **System message** when staff have left a message for you. Click it to read more.

When **Stop when empty** is on and the server is empty, the server shows when it will stop. See [Automation](/servers/pro/managing-server#automation).

::: tip Starting an Expired Server
**Start** on an expired server opens the server's page, where you see the renewal price before anything is charged. See [Renew an Expired Server](/servers/pro/billing#renew-an-expired-server).
:::

## Shared with You

Servers you help run for someone else are listed under **Shared with you**, below your own servers. Each one says **Owned by (username)**. Billing stays with the owner, so the price is not shown.

See [Team Access](/servers/pro/team-access) for how to join a server team or share your own server.

## Server States

| Dot | States |
|-----|--------|
| Green, pulsing | **Running** |
| Amber, pulsing | **Starting**, **Stopping**, **Restarting**, **Updating**, **Moving** or **Reinstalling** |
| Red | **Stopped** or **Crashed** |
| Grey or cyan | **Setup** or **Awaiting Setup**: the server has not been configured yet |

While a server is busy, its buttons are replaced by the state, for example **Starting...**, until it is done.

## Payments in Progress

If you paid for a new server or an extension and it is not ready yet, a box above your servers shows the payment and its status. Click **View** to see the details.

## Creating a New Server

Click **Create server** at the top of the list. See **[Creating a Pro Server](/servers/pro/creating-server)**.
