# GunGame v1.0

GunGame is a mod for Call of Duty 4 where each kill moves you up to the next weapon. The first player through every weapon wins.

## Select the Mod

- **Free server:** Pick **GunGame v1.0** under **Mod** when you create the server. The mod cannot be changed afterwards. To switch, create a new server.
- **Pro server:** Pick **GunGame v1.0** under **Mod** in **Game settings** on the [Pro Panel](https://fshost.me/pro/servers), save and restart the server.

## Manage the Server

Maps, game modes, kicks and bans use the normal CoD4 RCON commands. See [CoD4 RCON Commands](/games/cod4/rcon).

```bash
/rcon login type_rcon_pass_here
/rcon map mp_crash
```
