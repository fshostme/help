# CoDJumper v3.12b

CoDJumper is a bounce and jump mod for Call of Duty 4 by [CoDJumper.com](https://www.codjumper.com/). Instead of fighting, players work their way through jump maps using movement tricks such as bounces and strafe jumps.

## Select the Mod

- **Free server:** Pick **CoDJumper v3.12b** under **Mod** when you create the server. The mod cannot be changed afterwards. To switch, create a new server.
- **Pro server:** Pick **CoDJumper v3.12b** under **Mod** in **Game settings** on the [Pro Panel](https://fshost.me/pro/servers), save and restart the server.

## Jump Maps

CoDJumper is made for jump maps. The [custom map list](https://dl.fsho.st/cod4/usermaps/) shows the custom maps on our servers. Change map with RCON:

```bash
/rcon login type_rcon_pass_here
/rcon map mapnamehere
```

On a Pro server, you can also enter the map under **Map** in **Game settings** with **Enter a custom map name**.

## Manage the Server

Kicks, bans and the other server settings use the normal CoD4 RCON commands. See [CoD4 RCON Commands](/games/cod4/rcon).
