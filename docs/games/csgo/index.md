# CS:GO Documentation

Guides for managing and configuring your CS:GO game server on FSHOST.

## Getting Started

To manage your CS:GO server, you'll need to connect via RCON or use in-game chat commands. First, log in as an admin.

New here? Work through the sections in the order below. [Admin Login](./admin-login) is the one to start with, since most other commands need admin access first.

## Sections

| Section | Description |
| --- | --- |
| [Admin Login](./admin-login) | How to authenticate as a server admin using RCON or SourceMod |
| [General Settings](./general-settings) | Change map, password, hostname, and restart settings |
| [Config Files](./config-files) | Load predefined configs like competitive, casual, deathmatch, etc. |
| [In-Game Commands](./in-game-commands) | Full list of chat and RCON commands available on our servers |
| [Managing Players](./managing-players) | View status, kick, ban, and unban players |
| [Game Server Login Token](./gslt) | Create your own GSLT token - Game Server Login Token |
